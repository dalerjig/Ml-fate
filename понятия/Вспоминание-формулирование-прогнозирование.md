# Вспоминание-формулирование-прогнозирование

> [!definition] с. 28–29
> Базовая схема решения **по опыту**. Её книга переносит на компьютер.

1. **Вспомнить** похожие ситуации.
2. **Сформулировать** общее правило.
3. **Спрогнозировать** будущее этим правилом.

Правило не обязано быть истинным — это ставка по имеющейся информации.

## Машинный перевод схемы (с. 35)

| шаг | машина |
|---|---|
| вспомнить | большая таблица [[Данные\|данных]] |
| сформулировать | перебор правил/формул → выбор [[Модель\|модели]] |
| спрогнозировать | модель на будущих / новых данных |

[[Контролируемое обучение]] на с. 43 явно объявлено этой же схемой: вспомнить размеченный датасет → правило класса → [[Прогноз]] метки новой точки.
