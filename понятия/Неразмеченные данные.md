# Неразмеченные данные

> [!definition] с. 41
> Данные **без меток**: нет тега / нет столбца, который мы собираемся прогнозировать.

Пример: пачка писем без колонки «спам / ham» и без другой целевой колонки.

Противопоставлены [[Размеченные данные]]. Вход для [[Неконтролируемое обучение|неконтролируемого обучения]] (само определение ветви — после с. 43).
