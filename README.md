# Конспект «Грокаем машинное обучение» для Obsidian

Учебные заметки по книге Луиса Серрано *Грокаем машинное обучение* (Питер, 2024). Это **конспект определений и зависимостей**, не пересказ книги.

**Срез:** глава 1 и глава 2 **до страницы 43** книги. Предисловие, вступление, благодарности и «о книге» пропущены.

PDF в репозиторий не кладётся.

## Открыть в Obsidian

1. Поставь [Obsidian](https://obsidian.md).
2. Меню **Open folder as vault** → папка, где лежат `0 НАЧНИ ЗДЕСЬ.md` и `00 Карта.md`.
3. Если спросит Trust author — Trust.
4. Слева список файлов (иконка папки). Кликни `0 НАЧНИ ЗДЕСЬ`, потом `00 Карта`.
5. Если экран серый и пустой: `Ctrl+O` (Mac: `Cmd+O`) — это файлы. Без выбранной заметки Obsidian ничего не показывает.

Wiki-ссылки `[[так]]` — кликабельные. Граф собирается сам: узел = файл в `понятия/`, ребро = ссылка.

## Что внутри

| путь | содержание |
|---|---|
| `00 Карта.md` | оглавление vault |
| `01 По страницам.md` | определения **по номерам страниц книги** |
| `02 Что от чего зависит.md` | вложения, входы/выходы, что ломает прогноз |
| `главы/` | каркас гл. 1 и гл. 2 без воды |
| `понятия/` | атомарные заметки (ИИ, МО, модель, признак, метка, …) |
| `шаблоны/Определение.md` | шаблон на следующие страницы |

На с. 43 глава 2 обрывается: контролируемое обучение уже определено, регрессия/классификация — со с. 44.

## Соглашения

- Номера страниц — **книжные**, как в колонтитулах.
- Определение — своими словами; формулы и длинные примеры из книги не копируются.
- Если термин только назван, а определение позже — в заметке стоит `status: названо` или `вне-среза`.
- Frontmatter: `pages`, `depends_on`, теги `#иерархия` / `#данные` / `#процесс` / `#тип-мо` (цвета графа уже прописаны в `.obsidian/graph.json`).
